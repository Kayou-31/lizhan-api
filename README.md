# 厘站 API

一个认真做前端、把每个注册字段都设成“唯一值”的中转站玩笑。

## 打开

直接用浏览器打开 `index.html`，无需安装、构建或联网。

也可使用 `python -m http.server 4187 --bind 127.0.0.1` 在目录内启动本地预览。

## 页面

- 总览：主视觉、0.1 折价格展示和热门模型。
- 模型广场：15 家厂商、62 个模型条目，支持搜索和类型、厂商组合筛选。
- 模型定价：保留每百万 tokens 的原有价格，分列输入、输出和缓存命中；图像、视频等保留各自计价单位。
- 在线调试：模型切换、参数设置、输入框和访客提示，没有真实模型响应。
- 接入文档：格式示例，使用保留的 `.example` 域名。
- 分步注册：用户名、邮箱、手机号、密码、确认密码、性别和地区。

## 核心行为

任意输入，包括完全空白、错误格式或不一致的密码，都能进入确认页。

点击“确认注册”后返回填写页，全部七个字段标红。性别提示“不可重复选择”，其余六项提示“不可重复”。修改资料再提交仍然如此。永远不会注册成功。

## 数据与来源

没有服务器、注册接口、Cookie、浏览器存储、分析统计或第三方资源。输入仅暂存在当前页面；关闭注册窗口清空。页面 CSP 禁止网络连接及表单提交。请使用虚构资料，不输入真实密码。

模型名称依据 2026-10-07 查阅的官方目录。`model-sources.json` 保存厂商来源和已核对的调用 ID。未核对 ID 的条目只展示模型名，内部 `catalog-*` 仅用于本地界面选择。此目录为代表性覆盖，不宣称穷尽全部在售模型。

所有价格都是虚构基准价的 1%，用于 0.1 折演示，并非官方报价。输入、输出价格保持原值，文本生成模型的缓存命中演示价格为输入价的 10%；缓存命中指已缓存输入的费用，不与普通输入重复计费。不适用的类型显示“—”。本站与展示的模型厂商无关联，不提供真实模型服务、账户或支付功能。

## 部署

GitHub Pages 可使用 `main` 分支的根目录，无需构建。
